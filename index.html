01. Trayectoria

Un poco sobre mí y cómo trabajo

Mi nombre es Fernando Santos y soy desarrollador de software junior ubicado en Barranquilla, Colombia. Mi principal motivación en la programación es entender los sistemas desde su base: cómo estructurar una base de datos para que no se vuelva un cuello de botella, cómo diseñar una API intuitiva para el frontend y cómo desacoplar la lógica de negocio para que el código sea fácil de leer y testear.

Me formé de manera intensiva en Riwi, un programa de alto rendimiento donde trabajé en el desarrollo de aplicaciones bajo metodologías ágiles, resolución práctica de problemas de software y estándares de la industria. Allí consolidé mi enfoque en C# y el ecosistema .NET, así como en la creación de aplicaciones full-stack completas.

No me considero alguien que solo copia sintaxis; me gusta leer la documentación oficial, aprender de los errores y entender el porqué de las decisiones arquitectónicas: por qué separar contratos en interfaces, cómo manejar transacciones de base de datos seguras y cómo asegurar endpoints con JWT.

02. Proyectos

Trabajo y código que he construido

Ver más en GitHub
Full-Stack .NET 10 • React • PostgreSQL

Firmeza — Plataforma de Gestión de Suministros para Construcción

Sistema desarrollado para solucionar el descontrol en inventarios y pedidos de materiales de construcción entre múltiples almacenes y obras. Permite llevar el registro detallado de stock, control de proveedores y órdenes de despacho en tiempo real.

• Backend: Clean Architecture separada en Domain, Application, Infrastructure y WebAPI.
• Seguridad: Autenticación con JWT y control de permisos por roles (Administrador, Bodeguero, Residente de obra).
• Base de datos: PostgreSQL mediante Entity Framework Core, con transacciones para evitar inconsistencias de inventario.
• Frontend: React con TypeScript para interfaces tipadas, consumo modular de endpoints y manejo de estados.
C# .NET 10 Clean Architecture PostgreSQL EF Core React TypeScript JWT Docker
Ver código en GitHub
Backend Architecture ASP.NET Core • Docker

Frame — Plantilla Base para Web APIs en .NET

Boilerplate arquitectónico que utilizo para iniciar proyectos y microservicios en .NET sin tener que reconfigurar desde cero el manejo de errores, logs y contenedores.

• Manejo global de excepciones con el estándar RFC 7807 (ProblemDetails).
• Inyección de dependencias modular por ensamblados para mantener el program limpio.
• Dockerfile multi-stage configurado para generar imágenes ligeras y seguras.
